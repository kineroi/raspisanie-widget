# Моё расписание — виджет для Android

Виджет на главный экран: часы, день недели, какой урок идёт сейчас (с отсчётом до звонка),
перемены и «окна», и список всех уроков на сегодня с подсветкой текущего.

Расписание, темы уроков и домашние задания приложение берёт из BilimClass
(прошлая, текущая и следующая неделя) и обновляет само примерно раз в 3 часа.
Праздники и каникулы тоже учитываются.

## Установка на телефон

1. Откройте на телефоне ссылку:
   **https://github.com/kineroi/raspisanie-widget/releases/latest/download/raspisanie-widget.apk**
2. Скачанный файл `raspisanie-widget.apk` откройте и нажмите «Установить».
   Если телефон спросит — разрешите браузеру устанавливать приложения из неизвестных источников.
3. Откройте приложение «Моё расписание» и нажмите «Добавить виджет на главный экран».
   Или вручную: долгое нажатие на рабочем столе → «Виджеты» → «Моё расписание».

## Программа для Windows

Скачайте и запустите установщик:
**https://github.com/kineroi/raspisanie-widget/releases/latest/download/raspisanie-setup.exe**

Windows может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» →
«Выполнить в любом случае» (программа не подписана платным сертификатом).

- **Мини-окно** в углу экрана поверх всех окон: часы, текущий урок, отсчёт до звонка,
  уроки на день. Его можно перетаскивать мышью; «—» скрывает его, вернуть — значок в трее.
  Нажатие на урок открывает окно «Домашнее задание».
- **Основное окно** (☰ в мини-окне или двойной щелчок по значку в трее): недели, темы,
  домашка, вход в BilimClass, ключ нейросети, автозапуск.
- Программа запускается вместе с Windows и работает в трее; закрыть совсем — правый щелчок
  по значку в трее → «Выход».
- Телефон и компьютер берут данные из одного BilimClass. Вход и ключ нейросети вводятся
  на каждом устройстве отдельно; на компьютере они хранятся в зашифрованном виде.

## Подключение BilimClass

В приложении нажмите «Войти в BilimClass» и войдите как обычно. Вход происходит на
настоящей странице bilimclass.kz; логин и пароль приложение не сохраняет — оно забирает
только пропуск для загрузки расписания и хранит его в памяти телефона.
Пропуск продлевается сам. Если вход всё же устареет, приложение и виджет попросят войти снова.
Кнопка «Выйти» удаляет пропуск и сохранённое расписание.

## Успеваемость

Кнопка «📊 Успеваемость» (на телефоне — на главном экране, на ПК — в основном окне и в трее).
Данные журналов BilimClass только читаются, в BilimClass ничего не меняется.

- **Группа риска** — ученики, у которых выходит 2 или они на грани двойки/тройки
  (до 5% над границей). Сводка приходит по понедельникам в 07:45.
- **Сколько нужно на СОЧ** — сколько баллов надо набрать на СОЧ для 3, 4 и 5 при нынешних ФО и СОР.
- **Конец четверти** — за 7 дней до конца четверти и до срока итоговых: не выставленные итоговые,
  СОР/СОЧ без оценок, уроки без темы и без ДЗ. Напоминание каждый день в 16:00, если что-то не заполнено.

Расчёт как в журнале BilimClass: ФО 25%, СОР 25%, СОЧ 50%; меньше 40% — 2, 40–64% — 3,
65–84% — 4, от 85% — 5. Если BilimClass уже показывает рекомендуемую оценку — главная она.
Оценки учеников хранятся только на устройстве (на ПК — в зашифрованном виде).

## Напоминания

За 5 минут до каждого урока приходит уведомление: класс, время, тема.
Нажатие на уведомление открывает окно домашки этого урока. Учитываются праздники и каникулы
из BilimClass. Выключить: на телефоне — галочка на главном экране приложения;
на компьютере — в основном окне или в меню значка в трее.

## Домашнее задание

Нажмите на урок в виджете или в приложении — откроется окно «Домашнее задание»:

1. Напишите кратко, что задать (можно голосом через микрофон клавиатуры), например
   «стр 45 упр 3 письм, сл выуч».
2. «✨ Расписать» — нейросеть перепишет заметку в понятное задание на русском и английском.
   Без ключа или без интернета текст расписывается по простым правилам.
3. Проверьте и при необходимости исправьте текст.
4. Прикрепите фото или документы (или сфотографируйте страницу).
5. «Отправить в BilimClass» — домашка сохранится так же, как через сайт.
   Для сдвоенных уроков (7А + 8А) можно выбрать, каким классам задать.

Уже прикреплённые файлы видны в этом же окне, их можно удалить.

Ключ нейросети вставляется в карточке «Нейросеть (ключ API)» на главном экране. Ключ хранится
только на устройстве. Сервис определяется сам (`Ai.java`, `desktop/src/shared/ai.js`):

| Начало ключа | Сервис |
|---|---|
| `AIza…` | Google Gemini (бесплатный ключ: aistudio.google.com → Get API key) |
| `sk-ant-…` | Claude (Anthropic) |
| `gsk_…` | Groq |
| `sk-or-…` | OpenRouter |
| `sk-proj-…` | OpenAI |
| `sk-…` | проверяется по очереди: AnyModel, OpenAI, DeepSeek |
| другое | Mistral |

Для другого сервиса с запросами «как у OpenAI» укажите его адрес (например, `https://…/v1`)
во втором поле. После проверки ключа можно выбрать модель из списка.

## Запасное расписание

Пока BilimClass не подключён, используется расписание, записанное в файле
`app/src/main/java/kz/nikolaevka/raspisanie/Schedule.java`.

Измените строки вида
```
add(DayOfWeek.MONDAY, "09:00", "09:45", "7А + 8А");
```
сохраните (Commit) — GitHub сам соберёт новую версию за 3–5 минут.
Скачайте её по той же ссылке и установите поверх старой: виджет останется на месте.
